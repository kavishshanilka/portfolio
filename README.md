  - [Live Web Simulator](https://kavishshanilka.github.io/gridguard/)
  - [GitHub Repository](https://github.com/kavishshanilka/gridguard)
- **Smart Automatic Power Factor Corrector (APFC) Panel**: Closed-loop dynamic capacitor bank staging with CT/VT zero-crossing sensing, NI DAQ LabVIEW dashboards, and ESP32 OLED Telegram alerts.

- **Advanced Light Intensity Indicator (ALII)**: Zero-microcontroller discrete hardware signal processor with active 50–100 Hz analog ripple filtering and flip-flop windowed averaging.
